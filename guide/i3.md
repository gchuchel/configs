# i3wm — Гайд по управлению

## Основные сочетания

| Сочетание | Действие |
|-----------|----------|
| `Win+Enter` | Открыть терминал (alacritty) |
| `Win+D` | Запуск программ (dmenu) |
| `Win+Shift+Q` | Закрыть окно |
| `Win+Shift+E` | Выйти из i3 |
| `Win+Shift+C` | Перезагрузить конфиг i3 |
| `Win+Shift+R` | Перезапустить i3 |

## Навигация между окнами

| Сочетание | Действие |
|-----------|----------|
| `Win+J` / `Win+←` | Фокус влево |
| `Win+K` / `Win+↓` | Фокус вниз |
| `Win+L` / `Win+↑` | Фокус вверх |
| `Win+;` / `Win+→` | Фокус вправо |

## Перемещение окон

| Сочетание | Действие |
|-----------|----------|
| `Win+Shift+J` | Переместить влево |
| `Win+Shift+K` | Переместить вниз |
| `Win+Shift+L` | Переместить вверх |
| `Win+Shift+;` | Переместить вправо |

## Разделение окон (сплиты)

| Сочетание | Действие |
|-----------|----------|
| `Win+H` | Разделить по горизонтали |
| `Win+V` | Разделить по вертикали |
| `Win+Q` | Переключить ориентацию сплита |

## Изменение размера окон

`Win+R` — войти в режим изменения размера, затем:
- `J` / `←` — уменьшить ширину
- `;` / `→` — увеличить ширину
- `K` / `↓` — увеличить высоту
- `L` / `↑` — уменьшить высоту
- `Enter` / `Escape` — выйти из режима

## Рабочие столы (воркспейсы)

| Сочетание | Действие |
|-----------|----------|
| `Win+1-8` | Переключиться на рабочий стол 1-8 |
| `Win+Shift+1-8` | Переместить окно и перейти |
| `Win+Ctrl+1-8` | Переместить окно (остаться) |
| `Win+Ctrl+←` | Предыдущий рабочий стол |
| `Win+Ctrl+→` | Следующий рабочий стол |
| `Win+Ctrl+B` | Вернуться на предыдущий стол |
| `Win+Shift+B` | Браузер на рабочем столе 2 |

## Макеты окон

| Сочетание | Действие |
|-----------|----------|
| `Win+S` | Стопка (stacking) |
| `Win+W` | Вкладки (tabbed) |
| `Win+E` | Плитка (toggle split) |
| `Win+F` | На весь экран |
| `Win+Shift+Space` | Плавающее окно |

## Плавающие окна

| Сочетание | Действие |
|-----------|----------|
| `Win+Shift+Space` | Сделать окно плавающим / обратно |
| `Win+Space` | Переключить фокус между типами окон |
| `Win+Shift+S` | Закрепить окно на всех столах |
| `Win+A` | Фокус на родительский контейнер |

## Спрятанные окна (scratchpad)

| Сочетание | Действие |
|-----------|----------|
| `Win+Shift+-` | Спрятать окно |
| `Win+-` | Показать/спрятать из scratchpad |

## Границы окон

| Сочетание | Действие |
|-----------|----------|
| `Win+U` | Убрать границы |
| `Win+Y` | Тонкая граница (1px) |
| `Win+N` | Обычная граница |

## Приложения

| Сочетание | Действие |
|-----------|----------|
| `Win+F3` | Файловый менеджер (pcmanfm) |
| `Win+Ctrl+M` | Микшер громкости (alsamixer) |
| `Print` | Скриншот (flameshot) |
| `Win+Shift+B` | Браузер (qutebrowser) |

## Мультимедиа

| Клавиша | Действие |
|---------|----------|
| `XF86AudioRaiseVolume` | Громкость +5% |
| `XF86AudioLowerVolume` | Громкость -5% |
| `XF86AudioMute` | Выкл/вкл звук |

## Блокировка и питание

| Сочетание | Действие |
|-----------|----------|
| `Win+9` | Заблокировать экран |
| `Win+0` | Меню питания: `L`=lock, `E`=exit, `S`=suspend, `R`=reboot, `Shift+S`=shutdown |

## Закрепление приложений

- Браузер (`qutebrowser`) → рабочий стол 2
- Файловый менеджер (`pcmanfm`) → рабочий стол 3

## Автозапуск

- `nm-applet` — иконка сети в трее
- `dunst` — уведомления

## Смена раскладки

`Alt+Shift` — переключение US/RU

## Советы

- **dmenu** (`Win+D`) — набирай название программы для запуска
- **Выход из i3** — `Win+Shift+E`
- **Мышь** — `Win+ЛКМ` перетаскивает плавающие окна
